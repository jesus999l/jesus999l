# DriftWM

## A Custom Wayland Compositor Experiment

DriftWM is an exploration into what a desktop environment could become when designed around AI-native computing.

Instead of treating the desktop as a collection of windows, DriftWM experiments with:

- dynamic workspaces
- custom compositor behavior
- AI-assisted workflows
- persistent digital environments
- new ways of interacting with applications

## Technology

Built around:

- Rust
- Wayland
- Smithay
- Linux graphics stack

## Vision

Traditional desktops organize applications.

DriftWM explores organizing experiences.

The goal is not to replace existing desktop environments, but to explore new possibilities for human-computer interaction.

## Relationship With Echo

DriftWM acts as the visual environment where Echo can exist.

Together they explore:

- AI companions
- adaptive interfaces
- personal computing environments
- local-first interaction

## Status

Experimental development.

Current work focuses on compositor foundations, input handling, display systems, and companion integration.
