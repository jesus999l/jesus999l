# Echo Project Map

Echo is a collection of experiments exploring local-first AI, personal computing, and human-centered interfaces.

---

# Core Projects

## Echo Kernel
The orchestration layer connecting:
- AI models
- memory systems
- tools
- interfaces
- automation

Status:
Experimental development.

---

## DriftWM

A custom Wayland compositor built around exploring AI-native desktop environments.

Technologies:
- Rust
- Wayland
- Smithay
- Linux graphics stack

Explores:
- new workspace concepts
- adaptive interfaces
- companion environments

---

## Memory Vault

Personal knowledge and context systems.

Concepts:
- persistent memory
- knowledge graphs
- document relationships
- retrieval systems

---

## Voice Pipeline

Voice interaction experiments.

Components:
- wake word detection
- speech recognition
- text-to-speech
- conversational interfaces

---

## Infrastructure

Supporting systems:

- Docker services
- private search
- local databases
- automation tools
- synchronization experiments

---

# Development Philosophy

Echo is built around a simple idea:

Computers should understand people better.

Not by replacing human creativity, but by becoming a tool that helps people learn, create, organize, and explore.
