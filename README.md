# Echo

> A local-first personal AI companion built around memory, automation, voice, and human-centered computing.

![Echo](https://github.com/jesus999l.png)

## What is Echo?

Echo is an experiment in building a personal AI environment that lives with you.

Not just a chatbot.

A companion layer connecting:

- 🧠 Local AI models
- 🗂️ Persistent memory
- 🎙️ Voice interaction
- 🖥️ Custom desktop environments
- 📱 Multi-device experiences
- 🔎 Private knowledge search
- ⚙️ Automation and tools

## Current Systems

### Echo Kernel
The orchestration layer connecting models, memory, tools, and interfaces.

### Voice Pipeline
- Wake word detection
- Speech recognition
- Text-to-speech
- Voice experiments

### Memory System
- Knowledge graphs
- Vault integration
- Long-term context
- Personal information organization

### DriftWM
A custom Wayland compositor experiment built with Smithay.

Exploring:
- Custom desktop environments
- Infinite workspace concepts
- AI-native computing

## Philosophy

Technology should adapt to people.

Echo is built around the idea of a personal assistant that helps you learn, create, organize, and explore.

A tool.
A teacher.
A companion.
